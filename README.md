# Manuales Mónaco

Sitio público de los manuales para asesorados. Netlify lo publica solo cada vez que
se sube un cambio a `main`.

- Cada manual es una carpeta con su `index.html` (y sus videos si tiene).
- Para agregar uno: crear la carpeta, poner su `index.html` y sumarlo a la lista
  del `index.html` de la raíz.
- La fuente de trabajo de cada manual vive en el repo `Monaco`, en
  `plantillas/tramites/<manual>/`.

Aquí solo va contenido público: nada de datos de asesorados.
